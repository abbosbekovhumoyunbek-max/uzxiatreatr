# UZXIAtreatr — Kelajak Texnologiyalari va Intellektual Bilimlar Makoni

![UZXIAtreatr Platform](https://img.shields.io/badge/Status-Phase%200%20Completed-blueviolet) ![Stack](https://img.shields.io/badge/Stack-React%20%7C%20Vite%20%7C%20Vanilla%20CSS-00F0FF) ![Language](https://img.shields.io/badge/Language-Uzbek%20(O'zbek%20Tili)-success)

**UZXIAtreatr** is an advanced digital academy platform and media ecosystem built for an innovative university/academy environment. Fusing artificial intelligence education, interactive quizzes, dynamic news, event management, and multimedia storytelling, UZXIAtreatr sets a new standard for academic technology portals.

---

## 🌟 Key Features

1. **AI Academy**: Learning modules on Machine Learning, Generative AI, Prompt Engineering, AI Ethics, and practical tools.
2. **Interactive Zone**:
   - **Kun AI Fakti** (Daily AI Fact)
   - **Yangi Fakt Randomizer**: Instant technical facts on click.
   - **Interaktiv Mini-Viktorina**: Dynamic quiz platform with real-time scoring.
3. **Multimedia Hub**: High-definition video collection and filterable image gallery with fullscreen lightbox preview.
4. **News & Events**: Categorized academic news feed and interactive events calendar.
5. **Student Area**: Rich repository of learning tools, books, programming resources, and productivity guides.
6. **Responsive Design System**: Custom Navy/Cyan glassmorphism design tokens supporting seamless mobile, tablet, and desktop viewing.
